# Happy Birthday Plamena! ✨ Честит Рожден Ден, Пламена 🎂🇧🇬

A luxury, interactive 3D birthday celebration website crafted specially for **Plamena ("Plam buddy")** in Bulgaria.

Built with React (JSX), Tailwind CSS, Three.js, and Web Audio API.

## ✨ Highlights & Features

- **🎂 Interactive 3D Artisanal Cake**:
  - Multi-tier velvet fondant cake with pearl border, strawberry toppings, and gold pedestal.
  - 360-degree interactive orbit rotation on mouse drag and mobile touch.
  - Realistic flickering candle flames casting dynamic amber point lighting.
  - Interactive "Make a Wish & Blow Candles" button and tap trigger, with smoke particle physics, cheer fanfare, and golden confetti burst.
  - "Light Candles Again" action.

- **🎈 3D Floating Metallic Balloons Canopy**:
  - Metallic champagne gold, blush rose, and ruby balloons with swaying strings and realistic float physics.
  - Tap or click to pop balloons with satisfying sound effects and reveal secret birthday compliments.
  - "Release More Balloons" counter & launcher.

- **🎶 Polyphonic Acoustic Celebration Synthesizer**:
  - Multi-track custom musical arrangements with harmony chords, basslines, and bell leads:
    - *Serenade for Plam* (Emotional & Cinematic)
    - *Golden Friendship Waltz* (Luxury 3/4 celebration waltz)
    - *Bulgarian Rose Celebration* (Upbeat festive track)
  - Custom MP3 upload support directly in the player.

- **🇧🇬 Authentic Bulgarian Celebrations**:
  - Live Bulgaria time indicator.
  - Bilingual switcher: Seamlessly toggle between English and Bulgarian (*"Честит Рожден Ден!"*).
  - Traditional Bulgarian blessing cards with interactive celebration bell chimes.

- **💌 Sealed Personal Stationery Letter**:
  - Embossed golden wax seal with monogram **"P"**.
  - Clicking breaks the seal and unfolds the personal letter celebrating Plam buddy.
  - Interactive inline letter editor to customize personal memories and inside jokes.

- **✨ Star Constellation "Make a Wish"**:
  - Wish submission ritual with star burst animation and sealed memory cards.

- **📱 Fully Mobile Responsive**:
  - Optimized for phones, tablets, and desktops with smooth touch gestures.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
